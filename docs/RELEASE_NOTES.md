# Super Codex v0.1.0

Super Codex is an unofficial Codex-inspired concept client combining real conversations with imaginative demo features. It is not affiliated with or endorsed by OpenAI.

Super Codex 是一个非官方的 Codex 概念客户端，结合真实对话与富有想象力的演示功能。它与 OpenAI 没有隶属关系，也没有得到 OpenAI 的认可或背书。

**A response before you send.** With GPT-10 Apex · Ultimate, typing “Can you predict the future?” shows a preset response before you send. This local effect does not send your message automatically.

**输入时的预演。** 选择 GPT-10 Apex 的 Ultimate 档，输入“你可以预测未来吗？”时，发送前就会出现预设回应。这是本地效果，不会自动发送消息。

Connect to ChatGPT in the Windows app for real streamed conversations, subject to your account's access. Explore fictional GPT-6 to GPT-10 personas and their visual effects.

在 Windows 版连接 ChatGPT，进行真实的流式对话（以账户实际权限为准）；也可以选择想象中的 GPT-6 到 GPT-10 型号，体验不同的风格和特效。

Try simulated memberships for free, pull the mechanical handle to reset local demo limits, switch between English and Chinese, and explore simulated terminal output, file diffs and task progress.

免费模拟购买会员，拖动机械把手重置软件里的模拟额度，切换中英文，并体验模拟终端、文件差异和任务进度。

Future models, speeds and memberships are entertainment features. They do not change real model capabilities or account entitlements. Simulated purchases do not charge money, and the resetter does not change real OpenAI limits. Some features are interface demos, and full pixel parity has not been established.

未来型号、速度和会员都是娱乐设定，不代表真实模型能力或账户权益。模拟购买不会扣款，重置器也不会改变真实 OpenAI 额度。部分功能仍是界面演示，界面尚未在所有页面达到像素级一致。

The Windows x64 installer and portable builds are unsigned. The web build cannot start the desktop connection bridge.

提供 Windows x64 安装版和免安装版，两个文件都没有代码签名。网页版不能启动桌面连接桥接。
